JobScout

Un scan de 7 sites d'emploi, un score par offre calculé sur votre vrai profil, et un dossier de candidature (CV + lettre, une page, ATS) généré dans la langue de l'annonce — sans jamais inventer une compétence que vous n'avez pas.

Télécharger gratuitementVersion Pro

Windows, Mac, Linux (code source). Installeur Windows en version Pro.

Ce que JobScout fait

Chaque étape est visible et vérifiable. Vos données restent dans une base SQLite sur votre disque.

🔎

7 sources, un seul scan

Welcome to the Jungle, LinkedIn, APEC, HelloWork, France Travail, Talent.com (9 pays) et Civiweb pour les V.I.E. Chaque source s'active ou se coupe d'un clic.

🎯

Scoring local, instantané, gratuit

6 critères : secteur, compétences (une compétence prouvée par une expérience pèse plus qu'une compétence listée), pays, contrat, langue, durée V.I.E. Aucun appel IA, donc illimité.

📄

Votre CV lu et structuré

PDF, DOCX ou image (OCR). Extraction par Claude avec garde-fou anti-hallucination : une entreprise ou une compétence absente du CV est supprimée.

✍️

CV + lettre, une page, ATS

PDF et DOCX, boucle de rétrécissement garantissant une page A4, relecture par un correcteur, langue détectée par offre (français ou anglais).

🚫

Zéro invention, par construction

Chaque puce reformule un fait du profil. Un validateur compare le document généré au profil et retire ce qui n'est pas ancré. Les prompts appliquent une règle de calibration : la précision d'une affirmation ne dépasse jamais la preuve.

📊

Suivi des candidatures

Statuts, import et export Excel, message court pour les formulaires V.I.E, plusieurs profils.

Démarrer en 5 minutes (version gratuite)

Prérequis : Node.js 22.5 ou plus, et une clé API Anthropic (console.anthropic.com, facturée à l'usage) pour la génération de documents. Le scan et le scoring marchent sans clé.

  1. Récupérer le code
    git clone https://github.com/latenightsbeats1208-pixel/jobscout.git
cd jobscout
npm install
  2. Configurer la clé IA (optionnel)
    copy .env.example .env      # Windows   |   cp .env.example .env sur Mac/Linux
# puis ouvrir .env et coller ANTHROPIC_API_KEY=sk-ant-...
  3. Lancer
    npm run dev

    Ouvrir http://localhost:3000. L'assistant de démarrage vous demande votre CV et vos cibles (secteurs, pays, contrats).

  4. Scanner, trier, postuler

    Lancez un scan, triez par score, ouvrez une offre : le détail du score explique chaque point. « Générer le dossier » produit CV + lettre en PDF et DOCX.

  5. LinkedIn (optionnel)
    npx playwright install chromium

    Seule cette source a besoin d'un navigateur. Les autres fonctionnent sans.

Questions fréquentes

Mes données partent-elles quelque part ?

Non. Profil, CV, offres et documents vivent dans une base SQLite locale. Seuls les textes nécessaires à une génération sont envoyés à l'API du modèle (avec votre clé en version gratuite, via un proxy sans stockage en version Pro).

Le CV généré peut-il contenir des choses fausses ?

Le pipeline est conçu contre ça : consigne « zéro invention », relecture, puis un validateur qui supprime toute entreprise, compétence ou chiffre absent du profil. Relisez quand même avant d'envoyer, comme n'importe quel document.

Combien coûte l'IA en version gratuite ?

Environ 5 centimes par dossier (CV + lettre) sur le modèle par défaut, à votre charge via votre clé Anthropic. C'est du prépayé, pas un abonnement.

Windows affiche « Éditeur inconnu » à l'installation de la version Pro ?

Le premier installeur n'est pas encore signé par certificat. Cliquez « Informations complémentaires » puis « Exécuter quand même ». La signature arrive avec les prochaines versions.

Une source ne renvoie rien ?

Les sites tiers changent (anti-bot, API). Les sources France (APEC, HelloWork, France Travail, Talent) sont les plus fiables. Ouvrez une issue GitHub avec la source et la date : c'est corrigé en priorité.
