Genius Scout

Vous voulez placer vos prods ? Les portes, ce sont les producteurs qui travaillent déjà avec l'artiste. Genius Scout lit les crédits d'un album, en sort la liste des producteurs titre par titre, et retrouve leur Instagram avec une preuve — jamais un faux compte.

Télécharger gratuitementVersion Pro

Windows (installeur Pro), Mac et Linux via le code source. Accessible depuis votre téléphone sur le même Wi-Fi.

Ce que Genius Scout fait

Un scan = un album. Le résultat : des producteurs, leurs titres, leur Instagram, et un carnet de contacts prêt pour la prospection.

💿

Un lien d'album suffit

Collez un lien Spotify ou cherchez l'album sur Genius. La tracklist est reconstituée et chaque titre est rapproché entre les sources.

🧩

4 sources de crédits, fusionnées

Genius, Spotify (crédits du lecteur), MusicBrainz et Discogs. Les alias sont regroupés, un producteur cité par deux sources est marqué « double source ».

📸

Instagram retrouvé et vérifié

Candidats trouvés via Genius et Google, puis arbitrage : le handle ou le nom affiché doit correspondre au producteur, avec des indices musicaux. En cas de doute, la réponse est « non ». Option : validation par Claude sur les cas ambigus.

📧

Carnet de contacts

Emails et contacts management extraits des bios, statut « contacté », relance suggérée à 14 jours, export CSV.

🩺

Diagnostic avant chaque scan

Chrome dédié, Spotify, Instagram, Claude : chaque dépendance est testée et affichée avant de lancer. Un scan dégradé, ça se voit tout de suite.

🕓

File d'attente et historique

Lancez plusieurs albums, suivez la progression en direct, retrouvez tous les scans passés. Base SQLite locale, hors de tout dossier synchronisé.

Démarrer en 5 minutes (version gratuite)

Prérequis : Node.js 20.9 ou plus, Google Chrome, un compte Spotify et un compte Discogs (pour les clés gratuites).

  1. Récupérer le code
    git clone https://github.com/latenightsbeats1208-pixel/genius-scout.git
cd genius-scout
npm install
  2. Créer les clés (gratuites)

    Spotify : developer.spotify.com/dashboard → Create app → copier Client ID et Client Secret. Discogs : discogs.com/settings/developers → Generate token. Anthropic (optionnel, validation IA des cas ambigus) : console.anthropic.com.

    copy .env.local.example .env.local
# coller SPOTIFY_CLIENT_ID, SPOTIFY_CLIENT_SECRET, DISCOGS_TOKEN (et ANTHROPIC_API_KEY si voulu)
  3. Lancer
    Genius-Scout.bat        # Windows : ouvre le Chrome dédié + le serveur + l'app
npm run dev             # Mac/Linux : puis ouvrir http://localhost:3033

    Au premier lancement, connectez-vous à Spotify et Instagram dans le Chrome dédié (il garde la session).

  4. Scanner un album

    Collez un lien Spotify ou tapez « artiste album ». Le scan tourne en quelques minutes ; les producteurs apparaissent au fur et à mesure avec leur statut Instagram (confirmé / probable / introuvable).

  5. Prospecter

    Onglet Contacts : « Compléter les emails » lit les bios, puis marquez qui vous avez contacté. L'app rappelle les relances à 14 jours.

Questions fréquentes

Pourquoi un Chrome « dédié » ?

Spotify et Instagram bloquent les lectures anonymes. Genius Scout pilote un profil Chrome séparé, connecté à vos comptes, pour lire ce que vous verriez vous-même. Vos identifiants ne sont jamais stockés par l'app.

Est-ce qu'Instagram peut limiter mon compte ?

Oui si vous lisez des centaines de profils par jour. L'app espace les requêtes, met en cache 6 heures, et s'arrête 30 minutes dès qu'Instagram répond « trop de requêtes ». Restez raisonnable : quelques dizaines de profils par jour.

Comment l'app évite les faux comptes Instagram ?

Un compte n'est « confirmé » que si son handle ou son nom correspond au producteur ET qu'un indice musical ou une mention de l'artiste le corrobore. La validation IA (optionnelle) ne peut que rétrograder un candidat, jamais le promouvoir.

Sans clé Anthropic, ça marche ?

Oui. Le mode par défaut est heuristique. Claude n'intervient que sur les cas ambigus, si une clé est présente (quelques centimes par scan).

Où sont mes données ?

Dans GeniusScoutData à la racine de votre dossier utilisateur (base SQLite + profil Chrome). Hors OneDrive, hors des dossiers nettoyés automatiquement.
